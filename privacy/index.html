Privacy

Apostille Atlas is a static website. We don't run accounts, comments, advertising, or third-party tracking scripts, and we don't set cookies. The only form is the optional apostille request form, described below.

Hosting

The site is hosted on GitHub Pages. Like any web host, GitHub processes technical request data (such as IP address) to deliver pages and keep the service secure. See GitHub's privacy statement.

The apostille request form

If you use the "Get it done for me" form, we collect what you type: the document type, issuing state, destination country, deadline, number of documents, your name, your email, and any notes. The form is delivered to our inbox by FormSubmit, a form-to-email service, which processes the submission to deliver it.

We'll share your request with a trusted apostille service so they can quote and handle it. We use these details only to pass your request to one or more independent apostille services so they can reply to you with a quote, and to answer you ourselves. We don't sell them, add you to a mailing list, or use them for advertising. Once a service has your request, its own privacy policy applies. To have your request deleted, email us at the address below.
