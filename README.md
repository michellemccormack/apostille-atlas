# Apostille Atlas

An independent, source-cited guide to U.S. state apostille and authentication rules, published by Atlas Guides.

Live: https://apostillesteps.com/ (GitHub Pages, gh-pages branch; public/CNAME sets the domain; DNS on Vercel).

```
npm install
SITE_URL=https://apostillesteps.com BASE_PATH=/ npm run build
npm run preview
```

Defaults build for https://apostillesteps.com. For the github.io path: `SITE_URL=https://michellemccormack.github.io/apostille-atlas BASE_PATH=/apostille-atlas npm run build`.

`scripts/postbuild.mjs` writes `robots.txt` and `sitemap.xml`, adds `.nojekyll`, and prefixes root-relative links when `BASE_PATH` is not `/`.

## Publish

Copy the contents of `dist/` to the root of the `gh-pages` branch (keep `.nojekyll` and `CNAME`). Do not copy source files (`src/`, `scripts/`, `research/`, `package.json`, and so on) onto `gh-pages`.

## Add a page

1. Create `src/pages/<slug>.astro` using `layouts/Base.astro` (title, description props).
2. Cite every fact with `<Src href="..."/>`. If a figure isn't on a source page, put an em dash (—) in the table cell; never invent a value, and never show an "unverified", "not captured", or "affiliate link pending" badge on the published site.
3. Affiliate links: `<Aff id="notarize|bluenotary|onenotary|notarylive" .../>`. Only approved programs (listed in the approved set in Aff.astro, with the tracking href) show the small "affiliate link" tag. Unapproved Aff links must render as ordinary outbound links with no badge.
4. Link it from `src/pages/index.astro` and rebuild.

Logo SVGs in `public/` are generated by `scripts/generate-logo.py` (Colophon Seal, Newsreader wordmark, wax-wafer counter, brand `#6B2A3A`).
